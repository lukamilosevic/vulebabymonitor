### 🌟 Glavne Karakteristike
* **100% Zero-Cloud:** Zvuk i slika nikada ne napuštaju vašu kuću.
* **Maksimalna štednja baterije:** Silence-on-Wire protokol i dubok san procesora (Deep Sleep C-state).
* **Automatska VOX detekcija:** Zvuk se uključuje istog trenutka kada beba zaplače ili se pomeri.
* **Video na zahtev:** Hardverski Camera2 JPEG prenos (~5 fps radi nultog grejanja) i Picture-in-Picture (PiP).
* **Vojna enkripcija:** Automatska ECDH (X25519) + ChaCha20-Poly1305 AEAD enkripcija sa 4-cifrenim verifikacionim PIN-om.
* **Lokalni Web Prijemnik:** Pratite bebu iz web browsera na PC-ju, laptopu ili Smart TV-u bez ikakve instalacije.
